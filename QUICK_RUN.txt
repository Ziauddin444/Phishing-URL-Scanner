## 🆘 IF SOMETHING IS WRONG

### **"Cannot connect to API"**
- Did you run `python src/app.py`? 
- Check terminal for "Running on http://127.0.0.1:3000"

### **"Blank page"**
- Wait 2 seconds and refresh page (Cmd+R)
- Check if API is running in terminal

### **"Port 3000 in use"**
```bash
# Kill old process
lsof -i :3000 | grep LISTEN | awk '{print $2}' | xargs kill -9

# Then restart
python src/app.py
```
